# DSA-Java

A structured journey to learn and practice **Data Structures and Algorithms in Java**.

## 🎯 Goal

The goal of this repository is to build strong problem-solving skills by understanding DSA concepts and applying them across different coding platforms.

## 🧠 Learning Approach

Each topic follows the same learning cycle:

**GFG → LeetCode → Codeforces**

- **GFG** — Understand the concept and practice
- **LeetCode** — Apply the concept to problem-solving
- **Codeforces** — Challenge the understanding with competitive problems

The difficulty progresses from **Easy → Medium → Hard** as the concepts become stronger.

## 💻 Language

- Java

All solutions in this repository are written in Java.

## 📚 Platforms

- GeeksforGeeks
- LeetCode
- Codeforces
